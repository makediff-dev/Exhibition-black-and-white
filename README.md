# Exhibition Marketplace — UX Prototype

Чёрно-белый кликабельный UX-прототип маркетплейса выставочной индустрии (MVP).

**Подробная документация:** [README_PROTOTYPE.md](./README_PROTOTYPE.md)

## Быстрый старт

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000)

## Демо

Используйте меню **«Демо (инструмент прототипа)»** в левом нижнем углу для быстрого входа под любой ролью.

- Тестовый ИНН: `7701234567`
- Демо-код: `123456`
